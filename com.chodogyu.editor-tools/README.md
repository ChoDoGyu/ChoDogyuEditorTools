\# ChoDogyu General Editor Tools



Unity 프로젝트에서 반복적인 Editor 작업과 프로젝트 검증을 지원하기 위한 범용 Editor 전용 UPM 패키지입니다.



\## Package



`com.chodogyu.editor-tools`



\## Assembly



`CDG.EditorTools`



\## Requirements



\- Unity 6

\- Editor only



\## Dependencies



다른 ChoDogyu 패키지에 의존하지 않습니다.
